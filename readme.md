# 💖 Panira — Lovable To-Do List App

Panira is a beautiful and lovable To-Do List web application designed to help users organise their daily tasks with a clean, modern, and attractive UI/UX experience.

---

# ✨ Features

- 💖 Beautiful lovable theme
- 📝 Add daily tasks
- ✅ Mark tasks as completed
- 🗑 Delete tasks
- 🎨 Modern glassmorphism UI
- 💕 Floating heart animations
- 📱 Responsive design
- ⚡ Fast and lightweight
